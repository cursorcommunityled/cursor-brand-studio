## 📖 Overview

**Cursor Brand Studio** is a dedicated AI skill designed for Cursor ambassadors and community members. It empowers you to generate stunning, brand-aligned content—ranging from presentations and social media posts to landing pages and banners—all while strictly adhering to the official Cursor brand guidelines.

Whether you're hosting a community workshop or delivering an enterprise pitch, this skill ensures your content is professional, consistent, and undeniably Cursor.

## ✨ Capabilities

- **📊 Presentations (PPTX)**: Generate light (community/workshop) or dark (enterprise) theme slide decks with precise typography, layout, and contextual color usage.
- **📱 Social Media Posts**: Craft clear, concise, and confident posts for LinkedIn, Twitter/X, and more, perfectly capturing the Cursor voice (no hype, no buzzwords).
- **🌐 Landing Pages**: Create responsive HTML landing pages featuring automatic theme switching (light/dark mode) and brand-compliant styling.
- **🖼️ Banners & Images**: Design banners and cover images (SVG/HTML) in standard sizes with subtle logo integrations for social platforms and events.
- **📝 Written Documents**: Draft guides, one-pagers, and memos in Markdown or DOCX, ensuring the authentic Cursor tone is maintained throughout.

## ⚙️ How It Works

1. **Brand System Alignment**: The skill always starts by consulting the core `brand-system.md` to guarantee accurate color, typography, and logo usage.
2. **Intelligent Detection**: Automatically identifies your needs based on your request (e.g., "Cursor slides", "Cursor landing page").
3. **Pattern Application**: For presentations, it applies specific layout coordinates from defined light or dark theme patterns.
4. **Precision QA**: Verifies text colors against specific background regions, enforces spacing rules, and prevents common design errors (like using accent colors for headers).

## 🚀 Usage Examples

Trigger the skill by using keywords like "Cursor slides", "Cursor brand", or "ambassador content":

- **Presentations**: `"Create a Cursor intro workshop presentation with 10 slides"`
- **Enterprise Pitch**: `"Create a Cursor enterprise pitch, dark theme"`
- **Social Media**: `"Write a LinkedIn post announcing a Cursor meetup"`
- **Landing Page**: `"Generate an HTML landing page for a Cursor event"`

> **⚠️ Important:** This skill is strictly for generating Cursor-branded community content. It should **not** be used for general slide creation unrelated to the Cursor brand, nor for Cursor IDE technical support.

## 📦 Assets & Resources

The skill leverages a local library of curated assets:

- **Backgrounds**: Carefully crafted gradient blobs, clean grays, and pure blacks (`assets/backgrounds/`).
- **Logos**: Official Cursor cube and wordmarks in responsive styles (`assets/logos/`).
- **Fonts**: The official Cursor Gothic typeface (`assets/fonts/`).
